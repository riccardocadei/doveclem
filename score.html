How this thing sounds

Every groove is rendered inside an OfflineAudioContext — the app's own engine, the same nodes, no approximation — and measured. It is here to answer "did that change improve anything?" with a number instead of an opinion. This is not a judgement of taste: it says whether a mechanical fault is there or gone.

Development page. It loads index.html in a hidden iframe and reseeds Math.random with a fixed seed, so two measurements of the same groove differ only by what actually changed in the code.
